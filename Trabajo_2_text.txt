Objetivo: Realizar una segmentación de mercado para un bien (producto o servicio) a partir de un set de 
datos, y analizar una estrategia potencial de posicionamiento para los mercados meta que se consideren 
relevantes, desde la posición de una empresa que desea entrar al mercado. 
 
Actividad: Los estudiantes deberán considerar las características del bien y de la fuente de información 
para decidir sobre el mejor modelo empírico para el análisis, así como la interpretación de los resultados. 
Cada mercado tendrá asignado un set de datos y bien diferente. El grupo debe hacer una presentación de 
sus resultados (máximo 10 minutos, incluida la sección de preguntas) describiendo el contexto del 
mercado, características de las variables en la base de datos, los ajustes realizados a la base de datos para 
la estimación (e.g. limpieza de datos, creación de variables), el método de análisis, los resultados 
encontrados y las recomendaciones que se pueden realizar respecto del mercado. Para la limpieza de 
datos y estimación se debe usar un Notebook de Python y el código debe ser entregado junto con el 
informe autocontenido en el código (tiene que ser posible ejecutar el código en el set de datos sin errores). 
 
NOTA IMPORTANTE: Los datos entregados son data original, sin procesar. Lo anterior implica que se deben 
limpiar y clasificar las variables de forma adecuada, para poder ser analizadas posteriormente. 
 
Entregable: Codigo con el desarrollo del trabajo en formato IPYNB (informe con resultados). Presentación 
en formato PPT con el resumen del trabajo (o script .PY para Streamlit), un archivo XLSX con el resumen 
de la distribución de tareas y cumplimiento de actividades, y un archivo .DOCX con el resumen de la toma 
de decisiones y acuerdos alcanzados, que además incluye las interacciones con IA Generativa (los template 
se proveerán en el curso. Deben producirse tablas de descripción básica de los datos, así como tablas o 
figuras de resultados. Cualquier contenido adicional sobre el límite de páginas puede ser incluido como 
anexo.  
 
Tiempo: Los documentos pueden ser modificados vía Canvas por un integrante del grupo con plazo 
máximo el 27 de mayo a las 15:00 hrs. Las presentaciones se calendarizaran durante las practicas de la 
semana correspondiente.

Instrucciones generales 
 
Estimar modelos de segmentación tanto socio-demográfica como RFM para caracterizar los mercados 
meta relevantes a cada cliente. Debe compararse los modelos usando alguno de los métodos vistos en 
clases. En cada caso, el grupo debe (1) elegir las variables relevantes en cada modelo, (2) determinar el 
número óptimo de segmentos, (3) caracterizar los segmentos (nombrarlos) y (4) determinar aquellos 
segmentos (mercados meta) relevantes para la empresa. Las conclusiones deben hacer referencia a la 
estrategia de posicionamiento de la empresa para capturar los mercados meta relevantes, en base a sus 
análisis. NOTA IMPORTANTE: NO PUEDEN USAR IA GENERATIVA PARA CARACTERIZAR Y/O NOMBRAR 
LOS SEGMENTOS DE MERCADO .
